# Branch de mídia — reels cinematográficos

Esta branch existe só para servir os vídeos por URL pública,
porque a API do Buffer exige uma URL alcançável e não aceita upload.

Os arquivos são os reels de 19,9 s (4 imagens próprias por capítulo).
Não é código: nada aqui é importado pelo site.

Consumo: `https://raw.githubusercontent.com/Joao-Paixao90/Semeadores/videos-cinema/<capitulo>-cinema.mp4`
